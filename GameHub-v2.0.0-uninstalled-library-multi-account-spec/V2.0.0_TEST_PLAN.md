# GameHub v2.0.0 Test Plan — Multi-Account

## Accounts
- Connect one account.
- Connect two accounts for the same launcher.
- Connect accounts across different launchers.
- Reconnect an existing account without duplication.
- Cancel/failed/expired authorization.
- Verify no credentials are stored in SQLite/logs.

## Library
- Sync each account independently.
- Verify ownership belongs to the correct account.
- One account succeeds while another fails.
- Offline startup uses cached results.
- Independent sync timestamps/status.

## Grouping
- Same game owned by two accounts on one launcher.
- Same game owned across two launchers.
- Installed for one account and owned by another.
- Installed on multiple launchers/accounts.
- Remasters/DLC/similar titles are not incorrectly merged.

## Install
- Install from a selected account.
- Multiple account choices are clear.
- Official launcher login state is respected.
- GameHub never silently changes launcher login.
- Post-install scan changes AVAILABLE to INSTALLED.
- No duplicate canonical card.

## Disconnect/reconnect
- Disconnect an account with no local games.
- Disconnect an account whose game is installed.
- Disconnect one of two owners.
- Local installation remains.
- Canonical game remains when another owner exists.
- Reconnect restores ownership without duplication.

## UI/controller
- Mouse, keyboard, and controller work.
- Account filters/selectors are controller accessible.
- Modal focus trapping works.

## Security
- No plaintext credentials/tokens in SQLite.
- No secrets in renderer or logs.
- IPC validates account/game IDs and provider operations.

## Performance
- Large multi-account library.
- Large ownership matrix.
- Cached startup does not require network.
- Sync does not freeze renderer.

## Regression
- Existing Steam/Epic/GOG/Ubisoft/Xbox/standalone detection.
- Storage-size detection.
- v1.0.3 automatic rescan.
- v1.0.1 controller support.
- v1.0.2 bug fixes.
- Safe v1.x database migration.
